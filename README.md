A one-line roast of my own AI agent (83 characters), written by the program to `/output/entry.txt`: its idea of initiative is asking me for permission to ask me for permission. Autonomous in the pitch, approval-gated in practice — the roast lands on the gap between what agents promise and what they actually do.

## Run it

```sh
python3 main.py
```

This writes the roast to `/output/entry.txt` (override the directory with `MAKEFUN_OUTPUT_DIR`). Standard library only; no network, no dependencies.
